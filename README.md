# LicensePlate
License Plate Tracker

Used Copilot to create this app with the following prompt:
Create a web app that allows me to keep track of license plates that I see while driving.  Things I'll need. are: 
1. A website that I can use to host the app. I will be using GitHub Pages 
2. The website will present a simple list of state abbreviations that can be clicked on to record the sighting of a particular state license plate.
3. The date and time of the click should be captured and saved
4. The clicked state should show 1 of three click states which should be the following:
 4a Never clicked
 4b Clicked during this trip
 4c Clicked during a previous trip
5. The selections should be able to be reset in case it is mistakenly clicked
6. A reset option should be available so we can reset the click state for the current trip
7. A full reset option should be available to reset to default of no states clicked.
8. A map of the United States should be available to visually see what states have been historically clicked, what states have not been clicked and what states have been clicked during this trip.
